## 订单叠加回测（2026-05-17）

规则：基础 stake `10U`，胜单总返还 `1.8x`；若上一单胜，下一单使用上一单总返还额作为 stake，最多连续三单，即 `10U -> 18U -> 32.4U`，第三单后重置；任一亏损也重置。

因叠加只改变资金结算，不改变信号生成、开单时间、到期时间和胜负结果，本轮使用一年基准订单序列重算资金曲线，等价于在相同订单序列上应用新结算规则。

## 实盘运行反馈修正（2026-05-18）

对比 `20260516-020446` 与 `20260516-125015` 两版打包程序的实际订单，亏损主要集中在 30分钟 `放量急跌反抽`：截图中 30分钟样本出现多笔连续亏损，10分钟订单表现更稳。结合一年回测中 30分钟边际弱、最大回撤受30分钟拖累，本次策略收敛为：

同日运行订单数不一致的原因：

- 两个截图对应的是不同打包版本，`20260516-125015` 包内仍同时生成 10分钟/30分钟候选，且 `choose_best_candidate` 可选择30分钟。

- 若要比较策略本身，应以离线回测/统一订单回放为准；若要让页面在重启后复原当天模拟订单，需要另加“启动时从日内历史回放模拟订单但不发送 webhook”的模式。

## 《交易心理分析》复核

检索确认：中文版《交易心理分析》对应 Mark Douglas 的 `Trading in the Zone: Master the Market with Confidence, Discipline and a Winning Attitude`，刘真如译，电子工业出版社 2011 年版，浙江图书馆 OPAC 记录的 ISBN 为 `978-7-121-12752-6`。Apple Books / Penguin Random House 对英文版的介绍强调：本书重点不是预测市场，而是理解随机结果、风险现实和概率移动。

参考来源：

- 浙江图书馆 OPAC：《交易心理分析》书目信息，https://opac.zjlib.cn/opac/book/2256090
- Apple Books：`Trading in the Zone` 出版方简介，https://books.apple.com/us/book/trading-in-the-zone/id357986493

用于策略复核的原则：

1. **概率优势不是单笔预测**：一年回测基准 1265 单、胜率 58.50%、PnL +670U，只说明存在统计优势，不说明下一单确定会赢。因此策略不应因为某个月亏损就硬停，也不应因为最近连赢就放宽阈值。
2. **盈亏序列随机分布**：最大连亏 11 次说明“有效策略也会有连续亏损”。修正方向应是资金/暂停/观察层，而不是把亏损月份视作可迁移规律。
3. **一致执行比解释单笔结果更重要**：当前记录 `threshold_segment`、`reason`、`score`、`threshold`、`regime`、`rolling_edge` 是正确方向；下一步需要把“规则外人工干预、信号后是否追单、连续亏损后是否改变参数”作为审计字段，防止结果导向调参。
4. **每个市场时刻唯一**：MCP 当前显示 Fear & Greed 处于恐惧修复，30m 指标偏修复但 1m 有分歧；这支持把情绪/指标做成开单前风险标签，而不是用静态月份结论替代当前状态。
5. **预先接受风险**：当前单笔赔率固定为胜 +8U、负 -10U，盈亏平衡胜率 55.56%。策略文档和页面应继续显式展示：滚动 EV、最大回撤、最长连亏、当前连续亏损、日内/周内暂停原因。

结论：本书支持当前“观察/降权 + walk-forward”的修正方向；仍需完善的不是寻找更漂亮的月份切片，而是把开单前可见的弱化条件、执行纪律和风险接受状态记录得更完整。

后续待验证项：

- 给 `rolling_edge` 增加置信度字段，例如 Wilson 下界或 bootstrap EV 区间，避免样本刚满 15 笔就过度反应。
- `rolling_edge_degraded` 已进入实盘模拟硬门控；后续需要单独跟踪被拦截信号的后验表现，防止守卫过度过滤。
- 把社交情绪 MCP 的 API key 配好后，独立评估“社交量突增/情绪背离”是否能提前识别低胜率窗口。
- 增加执行纪律日志：参数版本、信号是否被人工跳过、是否在连续亏损后手动改阈值、是否违反最小间隔或最大持仓。

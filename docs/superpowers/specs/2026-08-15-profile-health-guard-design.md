# 画像短窗健康守卫设计

## 目标

在不改变10分钟候选生成、方向判断、7日画像入选规则、评分和每日08:00画像版本的前提下，增加一个只会收紧风险的4小时短窗健康层，并默认撤销北京时间12:00-18:00固定时段真实拦截。

## 现状与依据

- 完整自然日日均订单75.7笔，当前不需要继续放宽入口。
- `DPS-20260813-0800` 在方向拆分发布前已经低至33.33%，WebSocket发布后旧画像没有突降，排除这两项为主要起点。
- 当前7日画像对状态变化反应慢；当前周末LONG入选画像明显弱于同期未入选LONG。
- 2026-08-15固定时段守卫拦截的6个SHORT影子候选为5胜1负，固定时段限制不具备跨日稳定性。

## 设计边界

### 1. 固定时段守卫

保留 `TimePeriodGuard` 模块和显式启用能力，但将服务端及启动脚本默认值改为关闭。关闭后真实订单恢复原链路；通用观察候选仍正常保存和结算，因此画像统计不中断。生产发布不显式设置 `TIME_PERIOD_GUARD=1`。

### 2. 两层画像

第一层保持现有7日每日画像选择器不变，只负责形成候选池。

第二层新增 `ProfileHealthGuard`：

- 评估时点：北京时间 `00:00 / 04:00 / 08:00 / 12:00 / 16:00 / 20:00`；候选产生时只使用最近一个已经到达的评估边界。
- 短窗长度：评估边界前24小时。
- 统计范围：当前有效每日画像中，与候选方向一致的完整画像键。
- 数据来源：已经结算的观察候选，不读取未来结果或未结算结果。
- 独立性：每个完整画像键在上一笔10分钟观察到期前不重复计数。
- 方向隔离：LONG和SHORT分别计算，互不影响。
- 最小样本：12笔；不足时状态为 `WARMUP`，不改变开单。
- `HEALTHY`：胜率不低于55.56%且EV不低于0，保持原开单、第二席位和18U资格。
- `WATCH`：胜率不低于50%但低于55.56%，或EV低于0；允许该方向基础首单，禁止该方向第二席位和18U资格。
- `DEGRADED`：胜率低于50%；暂停该方向真实订单至下一次4小时边界重评。
- 守卫只会维持或收紧7日候选，不会晋升未入选画像，不会把LONG改成SHORT或反向操作。

### 3. 门禁顺序

1. 每日画像匹配；
2. 画像短窗健康评估；
3. 机械并发和方向间隔；
4. 现有画像退化、连续亏损、滚动优势等守卫；
5. WATCH第二席位限制；
6. 金额分配；WATCH禁止18U，HEALTHY/WARMUP沿用现状。

DEGRADED命中返回 `PROFILE_HEALTH_BLOCKED`；WATCH第二席位命中返回 `PROFILE_HEALTH_SECOND_ORDER_BLOCKED`。两类命中都保存观察候选，不发送Webhook、不创建真实订单。

### 4. 状态与审计

`/api/state` 新增 `profile_health_guard`，返回固定配置、当前方向、状态、评估边界、下次边界、样本、胜负、胜率、PnL、EV、是否阻止、是否允许第二席位和18U。

信号、模拟订单和观察候选保存以下结构化字段：

- `profile_health_status`
- `profile_health_sample_size`
- `profile_health_win_rate`
- `profile_health_ev`
- `profile_health_evaluated_at`

旧SQLite载荷缺少字段时使用默认值，不迁移或清空历史订单。

### 5. 配置与回滚

只新增一个外部开关：

- `PROFILE_HEALTH_GUARD=0`
- `--no-profile-health-guard`

默认启用。24小时、4小时、12样本、50%和55.56%均固定为代码常量，避免继续增加难以归因的生产参数。

### 6. 测试

- 纯函数：4小时边界、24小时窗口、未来结果排除、独立样本、方向隔离、WARMUP/HEALTHY/WATCH/DEGRADED。
- 状态集成：DEGRADED阻止真实订单；WATCH允许首单但禁第二单和18U；HEALTHY路径等价；未入选画像不适用。
- 时段守卫：默认关闭，显式启用仍保持原12:00-18:00影子行为。
- 服务与脚本：默认值、关闭参数、API字段、打包文件。
- 回归：完整单元测试、Python编译、Shell语法、JavaScript语法和Git差异检查。

## 非目标

- 不修改7日画像的60%门槛、样本数或排序。
- 不修改10分钟信号、MACD、RSI、BOLL、量能、评分或方向。
- 不根据4小时结果自动启用未入选画像。
- 不清空订单、观察画像、预热缓存或滚单资格。

# 10分钟策略粗筛回放设计

日期：2026-06-16

## 目标

在不修改当前实盘策略代码的前提下，使用本地 `BTCUSDT` 1分钟K线缓存，批量回放适合10分钟事件合约的候选策略，找出具备统计优势、可解释、后续可融合进当前程序的策略方向。

本设计只覆盖研究和回放评估，不改变线上策略、不部署、不修改 `app/strategy.py`、`app/state.py` 等业务代码。

## 数据与结算口径

数据来源：

- 本地缓存：`data/BTCUSDT-1m-*.zip`
- 读取方式：按 `open_time` 去重并升序合并。
- 时间范围：使用当前本地已有全部1分钟K线，不联网补数据。

结算口径：

- 每个候选信号只评估10分钟事件合约。
- 入场价：信号触发时最近已收盘1分钟K线的 `close`。
- 到期价：入场后第10分钟或之后第一根可用K线的 `close`。
- LONG：到期价 `>` 入场价为 `WIN`，否则 `LOSS`。
- SHORT：到期价 `<` 入场价为 `WIN`，否则 `LOSS`。
- 赢单净收益：`+8U`。
- 输单收益：`-10U`。
- 盈亏平衡胜率：`55.56%`。
- 默认同一时间只允许持有1单，最小开单间隔10分钟；粗筛时可额外输出“无冷却理论结果”作为参考。

## 候选策略集合

### 1. 微趋势延续 / 反延续

目的：验证短窗口价格动量对后10分钟方向是否有预测力。

候选规则：

- 最近3分钟上涨，做多10分钟。
- 最近5分钟上涨，做多10分钟。
- 最近3分钟下跌，做空10分钟。
- 最近5分钟下跌，做空10分钟。
- 上述规则同时测试最小涨跌幅阈值：`0/2/5/10/20/30/50/80/100 bps`。

扩展过滤：

- 成交量相对过去同长度窗口均值放大。
- 最近窗口实体占比高，过滤十字星。
- 上涨做多时过滤长上影；下跌做空时过滤长下影。

### 2. 急跌反抽 / 急涨回落

目的：验证当前策略核心“急跌后反抽”是否能被更简单、更稳定的前置信号表达，并同时评估反向空头观察规则。

候选规则：

- 最近3/5/10分钟跌幅超过阈值，且处于BOLL低位或短周期RSI低位，做多10分钟。
- 最近3/5/10分钟急跌后，最后1-2根出现下影承接或收盘回收，做多10分钟。
- 最近3/5/10分钟涨幅超过阈值，且处于BOLL高位或短周期RSI高位，做空10分钟。
- 最近3/5/10分钟急涨后，最后1-2根出现上影压制或收盘回落，做空10分钟。

阈值集合：

- 涨跌幅阈值：`10/20/30/50/80/100 bps`
- RSI阈值：低位 `30/35/40/45`，高位 `55/60/65/70`
- BOLL位置阈值：低位 `0.1/0.2/0.3/0.35`，高位 `0.65/0.7/0.8/0.9`

### 3. 假突破 / 失败突破

目的：寻找10分钟内常见的“突破后收不住”反向机会。

候选规则：

- 突破过去30/60分钟高点后，1-3分钟内重新收回区间，做空10分钟。
- 跌破过去30/60分钟低点后，1-3分钟内重新收回区间，做多10分钟。
- 突破时放量但收盘未站稳，优先视为失败突破。
- 贴近BOLL上轨失败做空，贴近BOLL下轨失败做多。

阈值集合：

- 回看区间：`30/60/120` 分钟
- 失败确认窗口：`1/2/3` 分钟
- 突破幅度：`0/5/10/20 bps`
- 成交量倍率：`1.0/1.2/1.5/2.0`

## 评价指标

每个候选策略至少输出：

- 策略名和参数。
- 方向：LONG / SHORT / 双向。
- 总单数。
- 胜负数。
- 胜率。
- 盈亏。
- 平均PnL。
- 总投入。
- ROI。
- 最大回撤。
- 最长连亏。
- 最近半年胜率和盈亏。
- 最近三个月胜率和盈亏。
- 按月份汇总。
- 按UTC小时汇总。
- 按WD/WE汇总。
- 按方向汇总。

入选候选池的最低标准：

- 总样本数 `>= 300`，除非明确标记为“小样本观察策略”。
- 总胜率 `> 55.56%`。
- 总PnL `> 0`。
- 最近半年PnL不为负。
- 最近三个月胜率不显著低于盈亏平衡线。

最终报告按以下优先级排序：

1. 总PnL。
2. 胜率超过盈亏平衡线的幅度。
3. 最大回撤较小。
4. 最近半年稳定性。
5. 单数适中，避免过低频或过高频。

## 实现边界

本轮只允许新增测试/研究文件，例如：

- `tests/test_10m_strategy_coarse_replay.py`
- 或 `scripts/research_10m_strategy_coarse_replay.py`

不允许修改：

- `app/strategy.py`
- `app/state.py`
- `app/backtest.py`
- `app/order_policy.py`
- `app/simulator.py`
- 线上部署配置

若需要复用指标计算，优先在测试/研究文件内调用已有只读函数；如调用成本太高，则在测试/研究文件内实现轻量计算，不移动到业务代码。

## 输出格式

回放运行后输出两类结果：

1. 控制台摘要：
   - 数据范围。
   - 总候选策略数。
   - 达标策略数。
   - Top 20 策略表。
   - 每类策略最佳参数。

2. JSON报告：
   - 保存到 `reports/10m_strategy_coarse_replay_YYYYMMDD_HHMMSS.json`。
   - 包含所有候选策略完整统计、分组统计、参数和口径说明。

如果当前执行环境不适合写 `reports/`，则写到当前数据工作区，并在回复里说明路径。

## 风险与防过拟合约束

- 不用全样本最佳结果直接作为线上参数。
- 所有候选策略都要检查最近半年和最近三个月表现。
- 小样本策略不得直接推荐上线，只能作为观察信号。
- 若某参数只在少数月份有效，必须标记为不稳定。
- 同一策略族内如果参数越收越窄才盈利，优先判定为过拟合风险。

## 完成标准

本轮回放完成后，应能回答：

1. 哪一类10分钟策略在当前两年数据上最有优势。
2. LONG 和 SHORT 是否分别存在可用策略。
3. 哪些策略虽然总收益高但近期失效。
4. 哪些策略适合作为当前程序的新增观察信号。
5. 哪些策略有资格进入下一轮“滚动训练 + 样本外验证”。
